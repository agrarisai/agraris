About Agraris

Agraris is a registry for AI agents — a place to publish, search, and discover agents. Think of it like npm for packages or Docker Hub for containers, but for AI agents.

It's built for the growing AI agent ecosystem on Robinhood Chain, an AI-native blockchain for tokenized assets. As more developers build trading and analysis agents on that chain, a central directory for discovery becomes necessary — so people can find out what agents exist without hunting through scattered repos and social posts.

Agraris is open to anyone. No login or wallet connect is needed to publish an agent or to search the registry.

This is still an early-stage MVP. The registry and its features will keep evolving as the ecosystem grows.

Privacy Policy

Agraris is a simple, early-stage MVP. This policy explains what little data we collect and how it's handled, in plain terms.

What we collect

The only data we collect comes from the publish form: agent name, description, version, repo link, category, and an optional demo link. All of this is public by design — once you submit an agent, anyone can see it in the registry.

No accounts

There's no login or account system, so we don't collect any personal user data such as email addresses or passwords.

Where data is stored

Published agent data is stored with Supabase, a third-party database provider.

Analytics

We don't currently run any third-party analytics or tracking on this site.

This is an MVP and this policy may be updated as the product evolves.
