API Reference

Data Agraris diakses lewat REST API otomatis dari Supabase — publik, read-only (GET saja), dan tidak perlu autentikasi khusus selain publishable key yang memang aman dipakai di client-side.

Base URL

Seluruh data agent ada di satu endpoint — tabel agents — yang di-expose oleh PostgREST bawaan Supabase. 

https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents

Read-only

Endpoint publik ini hanya untuk membaca data (GET). Jangan kirim POST, PATCH, atau DELETE ke API ini. Publish agent baru dan submit report tetap harus lewat form di situs — publish.html untuk agent baru, dan tombol report di halaman detail agent — bukan langsung lewat API.

Authentication

Tiap request wajib menyertakan publishable (anon) key Supabase. Key ini memang didesain aman dipakai di sisi client. Ganti YOUR_API_KEY di semua contoh dengan key kamu. Ada dua cara mengirimnya — pilih salah satu.

Lewat header apikey (disarankan):

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents" \
  -H "apikey: YOUR_API_KEY"

Atau lewat query string ?apikey=:

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?apikey=YOUR_API_KEY"

Versi fetch di JavaScript:

const res = await fetch(
  "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents",
  { headers: { apikey: "YOUR_API_KEY" } }
);
const agents = await res.json();

List all agents

Ambil seluruh agent yang terdaftar di registry. Tanpa parameter select, semua kolom dikembalikan. 

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?select=*" \
  -H "apikey: YOUR_API_KEY"

Get a single agent

Filter berdasarkan id untuk mengambil satu agent.

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?id=eq.AGENT_ID&select=*" \
  -H "apikey: YOUR_API_KEY"

Filter

Filter ditulis sebagai kolom=operator.nilai. Untuk kolom biasa pakai eq (sama dengan), misalnya hanya agent yang sudah terverifikasi: 

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?verified=eq.true" \
  -H "apikey: YOUR_API_KEY"

Kolom category berupa array (text[]), jadi ?category=eq.trading tidak akan cocok. Pakai operator cs (contains) untuk mencari agent yang punya tag tertentu. Flag -g mencegah curl membaca kurung kurawal sebagai glob. 

curl -g "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?category=cs.{trading}" \
  -H "apikey: YOUR_API_KEY"

Operator PostgREST lain seperti neq, gt, lt, ilike, dan is juga bisa dipakai — misalnya ?name=ilike.*bot* untuk pencarian nama tanpa peduli huruf besar/kecil.

Select columns

Pakai select untuk mengambil kolom tertentu saja, dipisah koma. Response jadi lebih kecil dan cepat. 

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?select=name,category,github_stars" \
  -H "apikey: YOUR_API_KEY"

Sort

Pakai order=kolom.asc atau order=kolom.desc. Contoh, urutkan dari GitHub stars terbanyak (tambahkan .nullslast supaya agent yang belum punya data stars ditaruh di akhir): 

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?order=github_stars.desc.nullslast" \
  -H "apikey: YOUR_API_KEY"

Limit & pagination

Pakai limit untuk membatasi jumlah baris, dan offset untuk halaman berikutnya. 

curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?limit=10" \
  -H "apikey: YOUR_API_KEY"

# halaman kedua
curl "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?limit=10&offset=10" \
  -H "apikey: YOUR_API_KEY"

Combining parameters

Semua parameter di atas bisa digabung dalam satu request dengan &. Contoh: 10 agent trading dengan GitHub stars terbanyak, hanya kolom yang dibutuhkan. 

curl -g "https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?category=cs.{trading}&select=name,category,github_stars&order=github_stars.desc.nullslast&limit=10" \
  -H "apikey: YOUR_API_KEY"

Request yang sama dengan fetch:

const params = new URLSearchParams({
  category: "cs.{trading}",
  select: "name,category,github_stars",
  order: "github_stars.desc.nullslast",
  limit: "10",
});

const res = await fetch(
  `https://gnydurjxrynqcbpkxopd.supabase.co/rest/v1/agents?${params}`,
  { headers: { apikey: "YOUR_API_KEY" } }
);
const topTradingAgents = await res.json();

Response schema

Setiap baris pada tabel agents punya kolom berikut.

Column Type Notes
iduuidPrimary key
nametextAgent name
descriptiontextShort summary of the agent
versiontexte.g. "1.0.0"
repo_urltextLink to source repo
categorytext[]Array of category / tool tags
demo_urltextNullable
created_attimestamptzWhen the agent was published
verifiedbooleanMarked "Verified" by Agraris
github_starsintegerNullable; refreshed daily from GitHub
github_updated_attimestamptzNullable; last push to the repo

Rate limits & fair use

API ini dibagikan bersama traffic situs Agraris sendiri, jadi tidak ada kuota khusus yang dipublikasikan. Mohon pakai secara wajar — cache hasil di sisi kamu kalau kamu melakukan fetch berulang, dan hindari polling yang terlalu agresif.
